# 🌐 Oryxgen AI — Chrome Extension

Official Chrome Extension for browser automation, web page analysis, error finding, and interactive AI assistance using Oryxgen AI's 80+ models.

---

## 🚀 Installation Guide (Google Chrome / Brave / Edge)

1. Open Google Chrome and navigate to:
   ```
   chrome://extensions
   ```
2. Turn ON **"Developer mode"** in the top-right corner.
3. Click **"Load unpacked"** in the top-left corner.
4. Select this directory:
   ```
   C:\Users\user\Desktop\OrygenAI\extension
   ```
5. Pin the **Oryxgen AI** icon to your Chrome toolbar.

---

## ⚡ Features

1. **Sahifani tahlil qilish (Analyze Page)**: Summarizes any article, documentation, or dashboard in seconds.
2. **Xatolarni topish (Find Errors)**: Automatically inspects console errors, broken elements, and runtime issues.
3. **80+ Models Selectable**: Claude Sonnet 5.5, Claude Opus 5.5, Nemotron 3 Ultra 550B, Nemotron 3 Super 120B, DeepSeek V4.1, Gemma 4, and more.
4. **Browser Automation**: Executes real DOM actions (clicking selectors, filling inputs, scrolling).
5. **Context Menu**: Right-click any selected text on any webpage to immediately explain or analyze.
